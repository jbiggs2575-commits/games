# Arcade Corner

A small, no-build browser project with two games:

- **Pong** — play against the computer. Move with **W/S** or the **Up/Down arrow keys**. First to five points wins.
- **Tic-Tac-Toe** — play against the computer as X, or switch to local two-player mode. X goes first.
- **Brick Breaker** — clear the brick wall with the ball. Move with **A/D**, the **Left/Right arrow keys**, or your mouse; press **Space** or click to launch.

## Run it

Open `index.html` in a browser. No install or build step is required.

## Files

- `index.html` — page structure and game controls
- `styles.css` — responsive visual styling
- `games.js` — game selection and game logic
